# Adhere to Docstring Specifications

1. Review the docstring of each function before implementation.
2. Ensure that all parameters and return values are correctly typed and documented.
3. Validate that the function logic aligns with the described behavior in the docstring.
4. Implement unit tests that cover all edge cases mentioned in the docstring.
5. If discrepancies are found, update either the implementation or the docstring to maintain consistency.
